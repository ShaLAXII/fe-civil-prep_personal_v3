# FE Civil Prep - Reviewed Source Questions

This is a static GitHub Pages website. No Mac command or server is required.

1. Extract the **one outer ZIP**. There are **no ZIP files inside**.
2. Upload all extracted files to a GitHub repository. Keep `index.html` at the root.
3. Enable GitHub Settings > Pages > Deploy from branch > main > /(root).
4. Open your GitHub Pages URL and choose **Question library** or **Checked practice**.

The book PDFs are not inside this compact website. Some reconstructed questions require checking the original reference source for missing figures, formulas, or ambiguous publisher keys.

**Accuracy:** All 1,854 indexed records have been structurally screened; only the items labeled manually checked have received targeted manual answer review. The other entries are provisional transcriptions or review-only references. See QUALITY_REVIEW.md and QUESTION_REVIEW_STATUS.csv.

This product is not affiliated with or endorsed by NCEES. Verify that any publication of publisher-derived question content is within the rights you have obtained.
